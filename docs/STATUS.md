## 已知問題 / 待確認
- **待驗證（2027 年 2～3 月）**：用 Yahoo 模擬選秀（Mock Draft）確認選秀進行中 draftresults 頁會即時更新；
  若不會，換成選秀室的即時資料（只要改 draft-source.js）。也要確認「打開 Yahoo 選秀室」按鈕開到的頁面有入口
- 模擬器的計分模型和排序用的是同一套 z 分數，結果會偏向均衡排序；是相對比較，不是絕對預測
- QS 是估算值（MLB API 沒有 QS）
- 守位只用 MLB 主守位，和 Yahoo 的守位資格不完全相同
- 選秀表沒有真實 ADP，「市場排名」是均衡價值的近似
- 撿人頁抓 Yahoo 網頁違反 Yahoo 使用條款（自用、量小）；Yahoo 改版時解析要跟著修
- 撿人推薦還沒考慮一週兩場先發、球員守位資格（只用 MLB 主守位）
- 模擬器沒有「每週最少 45 局」規則：App 有時建議第 6 個 SP 格空著（爛先發會拖累 ERA/WHIP）
- 手機上「全自動打完剩下的季」要 10～20 秒（有提示）
